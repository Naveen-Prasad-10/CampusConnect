# ABSTRACT
College event management often involves disseminating information across multiple plat
forms, leading to fragmented communication and reduced student participation. Tradi
tional approaches require students to manually search through various sources for up
dates, making the process inefficient and inaccessible. This project presents Campus
Connect, an AI-powered college event chatbot that enables students to query event
related information using natural language.
The system employs a scoring-based intent classification mechanism to identify user
requests such as ongoing events, upcoming programs, open registrations, or volunteering
opportunities. A structured data retrieval module dynamically fetches event details stored
in Google Sheets, ensuring real-time updates and easy management by event coordinators.
Based on the identified intent, the chatbot retrieves relevant event data and generates
structured responses with contextual clarity. The chatbot interface, developed using
React with Vite, supports responsive design and conversational interaction. The backend
efficiently processes user queries and maintains persistent chat history for improved user
experience.
This work demonstrates the effective integration of natural language processing tech
niques with structured event management systems, providing an intelligent and accessible
platform that enhances student engagement and simplifies event discovery within the col
lege ecosystem.

# Tech Stack
#### Programming Language: JavaScript, Python
#### Frameworks/Libraries: React (Vite), Flask/FastAPI, Pandas
#### Data Storage: Google Sheets API
#### NLP Techniques: Intent Classification, Keyword Matching
